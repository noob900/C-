# Utility Scripts

This folder contains general-purpose utility programs for data manipulation, visualization, and common tasks.

## 📁 Contents

### Calculators & Computing
- **Calculator.py** - Feature-rich calculator with advanced operations
- **ASCII_Media.py** - Convert images/media to ASCII art representations

### Data Processing & Visualization
- **scrapper.py** - Web scraping utility for data collection
- **class_plot.py** - Data classification and plotting utilities
- **Plot_scraps.py** - Miscellaneous plotting functions and examples

## 🛠️ Quick Reference

### ASCII Art Generator
```bash
python ASCII_Media.py
```
Converts images to ASCII art format for terminal display.

### Web Scraper
```bash
python scrapper.py
```
Collects data from websites efficiently.

### Plotting Tools
```bash
python class_plot.py       # Classification visualization
python Plot_scraps.py      # Other plotting examples
```

### Calculator
```bash
python Calculator.py       # Launch calculator
```

## 📋 Features

### Class Plot
- Data classification visualization
- Scatter plots with categorization
- Decision boundary plotting

### Scraper
- HTTP request handling
- HTML parsing
- Data extraction and storage

### ASCII Media
- Image to ASCII conversion
- Support for multiple formats
- Adjustable resolution and character sets

## 🔧 Dependencies
- matplotlib (plotting)
- requests (web scraping)
- PIL/Pillow (image processing)

## 📝 Notes
- Use responsibly when scraping websites (respect robots.txt)
- All plotting functions support both static and interactive displays
- ASCII conversion works best with simple, clear images
